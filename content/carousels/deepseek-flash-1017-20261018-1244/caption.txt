값은 그대로, 성능만 쑥 올린 오픈 AI 새 버전
쓰던 앱·API는 그대로인데, 하룻밤 새 모델만 똑똑해졌어요.

딥시크가 10월 17일 주력 모델을 DeepSeek-V4.1-Flash-1017로 바꿨습니다. 공식 웹·앱에도 적용됐고, API 호출 방법과 요금은 그대로입니다. 가중치는 MIT 라이선스로 허깅페이스에 공개됐어요(763B, 컨텍스트 100만 토큰).

딥시크 자체 측정으로 코딩 과제(DeepSWE v1.1)는 74.2에서 77.0으로, 터미널 작업(Terminal-Bench 4.0)은 31.2에서 42.3으로 올랐습니다. 작업 시간과 답변 길이도 줄여 더 싸고 빠르게 끝낸다고 밝혔어요. 모두 회사가 직접 잰 수치입니다.

같은 날 자체 검색 엔진도 Search·Fetch API로 열었습니다. 성공 1,000건당 0.75달러이고, DeepSeek Harness·Claude Code·Codex 안에서 부르는 서버 쪽 호출은 지금은 무료, 11월 1일(베이징 시각 0시)부터 과금됩니다.

API 모델 이름: deepseek-flash
요금(100만 토큰, 피크 시간 기준): 입력 0.3달러(캐시 미적용), 출력 1.2달러. 피크 외 시간은 절반이고, 주말은 종일 피크 외 요금이에요.
회사 기밀·개인정보는 넣기 전에 사내 규정부터 확인하세요.
