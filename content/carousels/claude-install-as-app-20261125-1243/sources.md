# Sources — claude-install-as-app-20261125-1243 (fact-checked 2026-11-25 KST)

1. Anthropic / Claude blog — "Turn artifacts into Mac and Windows apps"
   https://claude.com/resources/articles/install-as-app
   - "Starting today" Install as app rolling out in beta in Claude for Mac and Windows; own icon + own window; shareable
   - Can use Claude and connectors; auto-updates when artifact edited; app requests to Claude count toward plan usage limits
   - Examples: meeting prep page pulling from calendar/email; tracker for orders that need to ship that day
   - Notifications, menu bar/system tray; 3 permission levels (default=browser-level, app permissions, full computer access)
   - Permission covers current version only, asks again after every update; full access only for apps you made (or your org on Team/Enterprise); Anthropic doesn't review apps
   - No packaging/signing, no API key or separate login; all plans; HIPAA-ready & hybrid excluded; Team on by default with full access off; Enterprise off until owner turns on; must be online & signed in; Docs/Slides/Sheets artifacts can't be installed
2. Claude Help Center — "Install an artifact as an app"
   https://support.claude.com/en/articles/18516354-install-an-artifact-as-an-app
   - Plans: Free, Pro, Max, Ultra, Team, Enterprise (beta, rolling out); Claude for Mac/Windows version 6.28899.0 or later
   - Install: artifact title menu or right-click > Install as app > Install; also under Share
   - Prompt examples: Pomodoro timer in menu bar; small Mac app reminding to stretch every hour; Windows app renaming photos by date
   - Full access: run programs, read/change/delete files without asking each time
   - Limitations: not on Linux, web, mobile; template artifacts (Docs/Slides/Sheets), legacy, Cowork live artifacts excluded
   - Building an app and app requests count toward plan usage limits
