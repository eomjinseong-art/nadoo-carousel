AI가 짠 웹사이트, 빈틈을 줄인다 — 구글 크롬 모던 웹 가이던스 1.0

AI 코딩 도구로 만든 웹사이트는 일단 돌아가지만, 전문가가 보면 접근성·속도·보안에서 고칠 곳이 보입니다. 그 빈틈을 코딩 AI에게 미리 가르치는 도구가 정식판으로 나왔습니다.

구글 크롬 팀이 2026년 11월 10일 Modern Web Guidance(모던 웹 가이던스) 1.0을 공개했습니다. 코딩 AI(에이전트)에 웹 전문 지식, 모범 사례, 브라우저 호환성 정보를 넣어 주는 '스킬' 모음으로, 5월 구글 I/O 미리보기 이후 첫 정식 버전입니다. 이제 구글 크롬·마이크로소프트 엣지·모질라 파이어폭스·MDN 팀이 함께 관리합니다. 코드는 깃허브(GoogleChrome/modern-web-guidance)에 아파치 2.0 라이선스로 공개돼 있고, 11월 15일 기준 별은 1.5만 개를 넘었습니다.

구글이 꼽은, 최신 AI도 자주 놓치는 4가지: 접근성(키보드 이동, 움직임 줄이기 설정, 입력 오류 안내), 사용성(스와이프, 팝업 전환, 라이트·다크 테마), 속도(화면 밀림 방지 등), 보안(HTML 정화, 패스키 로그인). 1.0에는 사용법 가이드 203개(웹 기능 250개), 기존 코드에서 낡은 방식을 찾아 최신 방법과 연결해 주는 점검 기능, 인터넷 없이 되는 검색이 들어 있습니다. 점검 기능은 첫 버전이라 정해진 패턴만 찾습니다(전체 가이드의 약 20%).

사례: 일본 크리에이터 플랫폼 note가 실제 서비스 코드로 180회 평가한 결과, 최신 웹 검사 통과율이 61%에서 94%로 올랐다고 구글 블로그가 소개했습니다.

설치(프로젝트 폴더에서):
npx modern-web-guidance@latest install
이미 미리보기판을 썼다면:
npx modern-web-guidance@latest update
기존 코드 점검:
npx modern-web-guidance@latest legacy-scan
클로드 코드·코덱스·커서·안티그래비티·코파일럿 등의 플러그인 마켓에서도 설치할 수 있습니다.

주의: 코딩 AI가 내 프로젝트 코드를 직접 다룰 때 쓰는 도구입니다. 노코드 빌더 화면에서만 작업한다면 체감이 적을 수 있습니다. 성과 수치는 구글이 소개한 기업 사례 기준이고, 결과는 프로젝트마다 다릅니다.
