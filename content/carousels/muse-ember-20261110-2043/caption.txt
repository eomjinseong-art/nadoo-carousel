AI 반복 업무 비용 3분의 1 — 메타 뮤즈 엠버 공개

같은 점수의 AI보다 작업당 비용이 약 3분의 1인 초소형 모델이 나왔습니다.

메타가 2026년 11월 9일(미국 시간) 가장 작고 효율적인 모델 뮤즈 엠버(Muse Ember)를 공개했습니다. 에이전트가 하루 종일 반복하는 일, 즉 도구 호출·코딩 하위 작업·요청 분류·자료 추출·긴 문서 읽기를 맡기려고 만든 모델입니다. 글·이미지·음성·영상·PDF를 모두 입력으로 받고, 100만 토큰 맥락과 최대 약 52만 토큰 출력을 지원합니다.

요금(100만 토큰 기준, 입력 20만 토큰 이하): 입력 0.10달러, 출력 0.50달러, 캐시 입력 0.004달러입니다. 입력이 20만 토큰을 넘으면 입력 0.30달러·출력 1.50달러로 3배가 됩니다.

외부 평가 기관 아티피셜 애널리시스(Artificial Analysis) 지수에서 36점으로 클로드 하이쿠 5.5(최대 추론)와 같은 점수를 받았고, 작업당 비용은 약 0.14달러로 하이쿠(약 0.41달러)의 3분의 1 수준입니다. 메타 상위 모델 뮤즈 스파크 1.3(37점, 작업당 2.39달러)과 점수 차이는 1점입니다.

실무 활용(예시): 고객 문의 수천 건을 결제·오류·요청으로 나누기, 계약서·영수증·PDF에서 필요한 항목만 뽑아 표로 정리하기. 메타는 큰 모델(뮤즈 스파크·뮤즈 원더)이 계획을 세우고 반복 작업은 엠버에게 넘기는 조합을 권합니다.

쓰는 곳: 메타 모델 API와 뮤즈 코드(Muse Code, 종량제·모든 요금제). 모델명은 muse-ember-1.0이고, 이미 OpenAI 호환 SDK를 쓰고 있다면 dev.meta.ai에서 API 키를 만든 뒤 base_url을 메타 모델 API로 바꾸고 모델명만 muse-ember-1.0으로 지정하면 됩니다. 구글 클라우드·오라클 클라우드에서도 쓸 수 있습니다.

주의: 벤치마크 점수는 메타 발표 자료(일부 메타 자체 평가) 기준입니다. 실제 코딩 과제 평가(FrontierCode 2.0)에서는 하이쿠 5.5가 더 높았고, 메타도 어려운 단발 코딩 문제는 상위 모델을 쓰라고 안내합니다. 국내 결제·이용 조건은 직접 확인하세요.
