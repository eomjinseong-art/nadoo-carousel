국산 AI를 내 PC에서 무료로 — 크래프톤 오픈소스 LLM 라온-1 미니 정식 공개

국내 게임사가 처음부터 직접 만든 한국어 AI를 상업 용도까지 무료로 쓸 수 있게 됐습니다.

왜 지금: 크래프톤은 2026년 11월 25일 자체 개발 언어 모델 '라온-1 미니(Raon-1 mini)' 정식판을 공개했습니다. 여러 번 이어지는 대화에서 지시를 지키는지 보는 멀티챌린지(MultiChallenge) 점수는 64.9점으로 프리뷰보다 5.9점 올랐고, 크래프톤은 비교한 해외 동급 모델보다 높다고 밝혔습니다. 공식 API도 기간 한정 무료입니다(토큰 사용량·속도 제한은 적용).

정체: 크래프톤이 모델 설계부터 학습까지 직접 한 전문가 혼합(MoE) 모델입니다. 전체 288억 개 매개변수 중 43억 개만 켜서 답을 만들어 비용과 속도를 줄였습니다. 허깅페이스에 아파치 2.0 라이선스로 공개돼 연구·상업 목적 모두 무료입니다.

핵심 기능:
① 한국어 대화: 크래프톤 자체 한국어 채팅 평가에서 92.7점으로 비교한 해외 모델 6종보다 높았습니다. 비공개 자체 평가라는 점은 감안하세요.
② 긴 입력: 입력과 출력을 합쳐 262,144토큰(약 26만)까지 처리합니다.
③ 생각 깊이 조절: 생각 끄기(none)부터 최대(max)까지 6단계로 요청마다 고를 수 있고, 클로드 코드·코덱스 같은 코딩 에이전트에 연결하는 공식 안내도 있습니다.

알고 쓰기: 글자만 읽는 모델이라 이미지·파일은 이해하지 못합니다. 성능 수치는 크래프톤 발표·모델 카드 기준입니다. 내 PC 실행은 공식 llama.cpp가 아니라 크래프톤이 만든 전용 버전(raon-1-mini 브랜치)이 필요합니다. 모델 카드 기준 NVFP4 압축판은 24GB 그래픽카드 한 장에서 최대 길이 요청을 처리합니다.

시작 방법:
1) 설치 없이: 라온 콘솔 플레이그라운드에서 로그인 없이 체험(기간 한정 무료)
2) API: 라온 콘솔에 가입 → API 키 발급 → 모델 이름 raon-1-mini
3) 내 PC(llama.cpp, 공식 모델 카드 예시를 줄임, 샘플링 옵션 전체는 모델 카드 참고)
git clone -b raon-1-mini https://github.com/krafton-ai/llama.cpp
cd llama.cpp
cmake -B build -DGGML_CUDA=ON -DLLAMA_BUILD_BORINGSSL=ON
cmake --build build --config Release -j
./build/bin/llama-cli -hf KRAFTON/Raon-1-mini-gguf:Q4_K_M --reasoning on
(애플 실리콘 맥은 -DGGML_CUDA=ON을 빼고 빌드)
