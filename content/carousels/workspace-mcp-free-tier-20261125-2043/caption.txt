AI 비서 지메일 연결 하루 5천 번 무료 — 구글 워크스페이스 MCP 정식 출시

AI 비서를 지메일·드라이브에 붙여 쓰고 있다면, 이번 요금 규칙부터 확인하세요.

무엇이 바뀌었나: 구글이 11월 24일(미국 시간) 워크스페이스 MCP 서버와 공식 CLI(gwscli)를 정식 출시했습니다. MCP는 AI를 업무 도구에 연결하는 표준입니다. 지메일·드라이브·문서·시트·슬라이드·캘린더·채팅·태스크 8곳을 코드 없이 AI 에이전트에 연결할 수 있고, 킵은 곧 추가됩니다.

무료 vs 유료: 기본 등급(Standard)은 무료이고 결제 계정이나 카드가 필요 없습니다. MCP 서버는 프로젝트·제품당 하루 최대 5,000건까지 쓸 수 있고, 일부 도구는 한 번에 여러 건으로 계산됩니다. 한도를 넘으면 초기화될 때까지 요청이 제한됩니다. 더 필요하면 결제 계정을 연결해 확장 등급(Scaled)을 고릅니다.

날짜별로 바뀌는 점:
- 2027년 2월 1일: AI 에이전트는 REST API 대신 MCP로 워크스페이스 데이터에 접근해야 합니다. API를 직접 부르는 에이전트는 등급과 상관없이 기본 한도만 받습니다. 일부 데이터를 오래 보관하거나 API를 긁어 가는 것도 금지됩니다.
- 2027년 4월 1일: 확장 등급 과금 시작. 그중 지메일·캘린더·드라이브 MCP는 무료 구간 없이 첫 요청부터 요금이 붙습니다.

직원 입장: 관리자가 정한 규칙에 따라 외부 파일 읽기·데이터 공유 같은 민감한 작업 전에 확인 창이 뜰 수 있고, 기존 데이터 유출 방지 규칙과 감사 기록도 그대로 적용됩니다.

지금 할 일: 구글 클라우드 콘솔의 새 사용량 대시보드로 내 프로젝트가 기본 한도 안인지 확인하고, AI 연결은 2월 전에 MCP로 옮길 계획을 세우세요. 관리자는 관리 콘솔 보안 > API 제어에서 에이전트 접근·확인 규칙·감사 로그를 점검하면 됩니다. 구글은 활성 개발자의 99% 이상이 기본 등급 안에서 쓰고 있다고 밝혔습니다.
