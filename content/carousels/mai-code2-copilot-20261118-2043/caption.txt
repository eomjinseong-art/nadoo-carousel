코딩 AI 요금, 내년 5월까지 반값 — 마이크로소프트 MAI Code 2

코딩을 AI에 맡기는 비용, 지금 바꿀 이유가 생겼습니다.

마이크로소프트가 11월 17일 새 코딩 AI 모델 MAI Code 2와 MAI Code 2 Flash를 공개했고, 같은 날 깃허브 코파일럿(GitHub Copilot)에 들어왔습니다. MAI Code 2는 디버깅(버그 찾기)·여러 파일 수정·저장소 전체 이해 같은 큰 작업용, Code 2 Flash는 코드 설명·작은 수정·반복 수정 같은 가벼운 일상 작업용입니다.

요금(깃허브 코파일럿, 100만 토큰당): MAI Code 2는 2027년 5월 17일까지 할인가 입력 0.5달러·출력 2.5달러, 그 뒤 입력 1달러·출력 5달러입니다. Code 2 Flash는 할인가 입력 0.05달러·출력 0.25달러, 그 뒤 입력 0.1달러·출력 0.5달러입니다. 지금 가격이 정가의 딱 절반입니다.

누가 쓸 수 있나: Code 2 Flash는 코파일럿 무료(Free)·학생 플랜부터 프로·프로+·맥스·비즈니스·엔터프라이즈까지, Code 2는 프로 이상 유료 플랜에서 고를 수 있습니다. VS Code·비주얼 스튜디오·코파일럿 CLI·github.com·모바일 앱 등의 모델 선택 메뉴에서 바로 바꿀 수 있습니다. 회사(비즈니스·엔터프라이즈)는 새 모델이 기본으로 켜지지만, 관리자가 끄면 보이지 않습니다.

마이크로소프트 자체 평가로는 MAI Code 2가 GPT-6.1 솔 성능의 98%를 약 40% 비용(할인가 기준)으로 낸다고 합니다. 다만 아직 어려운 과학 연구나 아주 긴 에이전트 작업에 맞춰 조정된 모델은 아니라고 직접 밝혔습니다. 성능·비용은 작업마다 다르니, 할인이 끝나기 전에 같은 작업을 지금 쓰는 모델과 나란히 돌려 비교해 보세요.
