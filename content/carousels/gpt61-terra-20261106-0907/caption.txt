API 요금 절반, GPT-6.1 테라로 화면 작업까지

오픈AI가 컴퓨터 사용(화면을 보고 조작)과 시각 추론을 강조한 GPT-6.1 테라를 공개했습니다. 표준 API 요금은 GPT-5.6 테라·GPT-6.1 솔 대비 50% 낮습니다.

오픈AI 공식(2026-10-26 뉴스룸 표기): https://openai.com/index/introducing-gpt-6-1-terra/

핵심 숫자(공식 단가)
입력 100만 토큰 1달러
캐시 입력 100만 토큰 0.05달러
출력 100만 토큰 5달러
API 모델 이름: gpt-6.1-terra

어디서 쓰나
챗GPT Work와 코덱스(Codex)에서 Plus·Pro·Enterprise·Edu 사용자에게 제공됩니다. Work·코덱스에서는 같은 사용 한도로 더 많은 일을 돌릴 수 있다고 안내합니다(요금 절반은 표준 API 단가 기준).

실무에서 바뀌는 점
① 대량 자동화·양식 입력 API 비용을 다시 계산해 볼 만합니다.
② 제안서 초안, 도면 해석, 영상 편집처럼 화면 작업 흐름을 시험해 보세요.
③ 같은 사용 한도로 더 많은 일을 돌릴 수 있는지 Work·코덱스에서 확인하세요.

주의
복잡한 코딩은 GPT-6.1 솔이나 GPT-6 아스트라가 더 나을 수 있습니다. 벤치·속도·요금 비교는 공식 발표 기준이며, 실제 청구액은 사용량에 따라 달라질 수 있습니다.

확인 체크리스트

③ 자동화 한 달 예상 비용을 다시 계산
