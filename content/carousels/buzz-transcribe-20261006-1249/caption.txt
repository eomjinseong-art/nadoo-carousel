회의 녹음 받아쓰기, 내 PC에서 무료로 끝내기

1시간 회의 녹음, 아직도 다시 들으면서 받아 적으세요?

Buzz(버즈)는 OpenAI 음성 인식 모델 Whisper(위스퍼)로 녹음·영상 파일을 글자로 바꿔 주는 무료 오픈소스 앱입니다. 깃허브 별 2.1만, MIT 라이선스.
파일을 서버에 올리지 않고 내 컴퓨터 안에서 처리합니다. (처음 음성 인식 모델을 내려받을 때와 유튜브 링크를 받아쓸 때는 인터넷이 필요해요.)

✔ 녹음·영상 파일, 유튜브 링크 받아쓰기
✔ 마이크 소리 실시간 받아쓰기
✔ TXT·SRT·VTT 파일로 저장, 영어 번역

설치는 이렇게 하세요.
윈도·맥: 깃허브 README에 연결된 SourceForge에서 설치 파일을 받습니다. 윈도에서 경고 창이 뜨면 '추가 정보'를 누른 뒤 '실행'을 누르세요.
최신 맥 버전은 애플 실리콘(M 칩) 전용이고, 인텔 맥은 1.4.5 버전까지 쓸 수 있어요.
파이썬으로 설치하려면 ffmpeg와 Python 3.12를 준비한 뒤 아래 명령어를 쓰세요.
pip install buzz-captions
python -m buzz
컴퓨터 사양이 낮으면 받아쓰기에 시간이 오래 걸릴 수 있어요.

가장 받아쓰고 싶은 녹음은 뭔가요? 회의, 강의, 통화 중 하나만 댓글로 알려 주세요.
