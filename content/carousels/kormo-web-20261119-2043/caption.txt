말로 시키면 웹 클릭 대행 — 카이스트 오픈소스 KORMo-Web

한국어로 할 일을 적으면, 내 컴퓨터에서 도는 AI가 웹 화면을 보고 대신 클릭합니다.

카이스트 MLP 연구실이 11월 중순 한국어 웹 특화 에이전트 모델 KORMo-Web을 허깅페이스에 무료로 공개했고, 11월 17일에는 바로 써 볼 수 있는 크롬 확장 프로그램도 내놓았습니다. 크기는 4B·9B·11B 세 가지이고, 한국인이 자주 쓰는 사이트를 포함한 한영 웹 학습 자료 1,000만 건 이상과 실제 웹 사용 기록 10만 건 이상으로 학습했습니다. Apache 2.0 라이선스라 상업적 이용도 가능합니다.

핵심 기능 1: 한국어·영어로 지시합니다. 공식 예시는 "다나와에서 50만 원 이하, 10인치 이상 태블릿 3개를 찾아서 가격을 알려줘"입니다. 짧은 명령도, 길게 풀어 쓴 지시도 이해합니다.

핵심 기능 2: 화면 캡처만 보고 판단합니다. 사람처럼 화면을 보고, 짧게 생각한 뒤 한 번에 한 동작씩(클릭·입력·스크롤 등) 실행하고, 결과를 다음 화면에서 다시 확인합니다.

핵심 기능 3: 한 사이트에서 찾고 다른 사이트에서 확인하는 식으로 여러 사이트와 탭을 스스로 오갑니다. 원하면 디스코드 봇으로 원격 지시도 할 수 있습니다.

성능(연구실 발표 기준, 실제 웹사이트 작업 612개): 한국어 작업 성공률은 4B 42.3%, 9B 48.1%로, 비교한 공개 모델 중 가장 높았습니다. 다만 같은 평가에서 유료 최상위 모델(GPT-6-luna)은 65.7%였고, 아직 절반 넘는 작업은 실패한다는 뜻이니 결과는 꼭 직접 확인하세요.

이런 분께 맞습니다(예시): 가격 비교·자료 조사처럼 같은 사이트에서 같은 클릭을 반복하는 직장인·마케터. 매번 완벽한 결과가 바로 필요하다면 아직 맞지 않을 수 있습니다.

시작 방법: 애플 실리콘 맥(메모리 16GB 이상이면 4B 4비트 모델) 또는 GPU 서버에서 모델을 띄우고, 크롬 확장 프로그램을 연결합니다. 터미널 사용이 필요합니다.
모델: huggingface.co/collections/KORMo-VL/kormo-web
확장 프로그램: github.com/MLP-Lab/KORMo-Web-Extension
맥 설치(4B 4비트 기준):
uv venv --python 3.12
source .venv/bin/activate
uv pip install "vllm-mlx>=0.6.0" huggingface_hub
hf download KORMo-VL/KORMo-Web-4B-mlx-4bit --local-dir ~/models/KORMo-Web-4B-mlx-4bit
vllm-mlx serve ~/models/KORMo-Web-4B-mlx-4bit --port 8010 --served-model-name KORMo-VL/KORMo-Web-4B-mlx-4bit --enable-auto-tool-choice --tool-call-parser auto
git clone https://github.com/MLP-Lab/KORMo-Web-Extension.git
그다음 크롬 주소창에 chrome://extensions → 개발자 모드 켜기 → '압축해제된 확장 프로그램을 로드합니다'로 받은 폴더 선택 → 사이드 패널 'GUI 에이전트'에서 실행.

주의: 맥에서 직접 돌리면 속도가 느린 편이라 연구실은 가볍게 시험할 때가 아니면 GPU 서버를 권합니다. 결제·발송처럼 되돌리기 어려운 일은 맡기지 말고, 회사 계정에서 쓰기 전에는 사내 보안 규정을 먼저 확인하세요.
