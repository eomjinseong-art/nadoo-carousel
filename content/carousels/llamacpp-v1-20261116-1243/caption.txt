월 0원 AI를 내 PC에서 — 로컬 AI 엔진 llama.cpp 1.0 정식판

구독료 없이 내 컴퓨터 안에서 AI를 돌리는 엔진이 3년 반 만에 정식 1.0이 됐습니다. 대화 내용이 PC 밖으로 나가지 않아서, 회사 문서처럼 밖에 올리기 곤란한 자료를 다룰 때 특히 쓸모가 있습니다.

허깅페이스의 ggml-org 팀이 2026년 11월 13일 llama.cpp(라마 씨피피) v1.0.0을 공개했습니다. 내 PC에서 AI 모델을 돌리는 오픈소스 엔진으로 MIT 라이선스이고, 11월 16일 기준 깃허브 별은 13.5만 개를 넘었습니다. 많은 앱이 이 엔진에 기대고 있는 만큼, 앞으로 호환이 깨지는 큰 변경은 주 버전 번호를 올려 미리 알리겠다고 밝혔습니다.

1.0에서 달라진 점: 150개가 넘는 모델 구조 지원(키미 K3.1 프로 등 새 모델 추가), 대화 묶음·마크다운 편집기를 넣은 새 웹 채팅 화면, 글을 소리로 읽어 주는 음성 기능 연결, 로컬 AI 서버 보안 강화(요청 위조·주소 우회 공격 대비, 도구 실행 취소 보강). 윈도우·맥·리눅스·안드로이드·iOS용 실행 파일을 제공합니다.

가장 쉬운 시작은 같은 팀이 만든 무료 앱 라마(Llama)입니다. 맥은 메뉴 막대, 윈도우 11은 시스템 트레이에서 실행되고, 내 PC 사양에 맞는 모델을 추천해 클릭 한 번으로 받게 해 줍니다.
맥 앱: brew install --cask llama-app
윈도우 앱: github.com/ggml-org/Llama-Windows 의 Releases에서 .msixbundle 파일을 받아 더블클릭
엔진만 직접 설치하려면:
윈도우: winget install llama.cpp
맥·리눅스: brew install llama.cpp
작은 모델로 바로 대화: llama cli -hf ggml-org/Qwen3.5-0.8B-GGUF

주의: 내 PC에서 도는 만큼 속도와 품질은 PC 사양과 모델 크기에 달려 있습니다. 최상위 클라우드 AI 수준이 꼭 필요하다면 체감이 다를 수 있고, 사양이 낮다면 작은 모델부터 시작하세요. 라마 앱은 아직 0.x 버전입니다.
