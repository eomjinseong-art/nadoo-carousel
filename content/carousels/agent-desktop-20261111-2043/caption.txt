AI가 PC 앱을 대신 클릭 — 버셀 에이전트 데스크톱 오픈소스

AI에게 클릭을 맡기는 일이 이제 브라우저 밖, PC 앱까지 왔습니다.

버셀 랩스(Vercel Labs)가 공개한 오픈소스 도구 agent-desktop(에이전트 데스크톱)이 2026년 10월 28일 1.0 정식판을 낸 뒤 빠르게 주목받고 있습니다. 11월 11일 기준 깃허브 별은 약 2.1만 개, 라이선스는 아파치 2.0입니다. 맥(macOS 13 이상)·윈도우(Windows 10 1809 이상)·리눅스(Ubuntu 24.04 이상)에서 돌아가고, 11월 5일 나온 1.2 버전에서 MCP(AI 앱과 도구를 잇는 표준) 서버 기능이 추가됐습니다.

어떻게 일하나: 화면을 캡처해 픽셀로 위치를 짐작하지 않고, 운영체제의 접근성 정보(앱 속 버튼·입력칸 목록)를 읽어 요소마다 이름표(ref)를 붙입니다. AI가 이름표를 골라 클릭·입력한 뒤 다시 읽어 결과를 확인합니다. 기본은 화면 뒤에서 작동해 마우스를 움직이거나 창을 빼앗지 않습니다.

주의: 이 도구 안에는 AI 모델이 없습니다. 코딩 AI(에이전트)나 스크립트가 명령을 불러 쓰는 방식이라 초보자용 앱은 아닙니다. 앱이 접근성 정보를 내주지 않으면 다룰 수 없고, 웹페이지 자동화는 같은 팀의 agent-browser가 맡습니다. 스냅샷·클립보드·스크린샷에 개인 정보가 담길 수 있으니 공개 기록에 올리지 마세요. 업무에 쓰기 전 테스트용 PC에서 먼저 시험해 보세요.

설치와 시작(캡션 전용):
npm install -g agent-desktop
agent-desktop status
agent-desktop skills get desktop
맥에서는 agent-desktop permissions --guide로 손쉬운 사용 권한을 허용합니다.

깃허브: https://github.com/vercel-labs/agent-desktop
