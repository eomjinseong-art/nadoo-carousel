# Sources — ChatGPT 브라우저 확장 업그레이드 (탭 언급·옆 창 대화·브라우저 조작) (2026-10-16 20:43 슬롯)

## Official (primary)
- OpenAI 공식 문서 "Browser extension" (ChatGPT Learn): https://learn.chatgpt.com/docs/chrome-extension  (md: https://learn.chatgpt.com/docs/chrome-extension.md)
  - Chrome·Edge·Brave·Opera·Vivaldi 5개 브라우저: 탭 언급·브라우저 조작 지원 / 옆 창(side chat)은 Chrome·Edge·Brave·Vivaldi, Opera 제외
  - 이미 로그인된 사이트(LinkedIn, Salesforce, Gmail, 사내 도구) 읽기·작업 가능
  - 열린 탭을 멘션해 맥락으로 사용, 텍스트 드래그해 해당 부분만 질문, 우클릭 "Ask ChatGPT"
  - 유튜브: 자막이 있으면 타임스탬프 자막으로 설명·요약·질문
  - 설정: ChatGPT 데스크톱 앱 Settings > Computer Use → 브라우저 선택·Install → Work 또는 Codex 채팅에서 @멘션
  - 사이트 접근: 새 사이트마다 먼저 물어봄 (Allow once / Allow for this site / Allow for all sites / Decline). "Allow for all sites"는 Elevated risk 표시
  - 페이지 내용은 신뢰하지 말 것(untrusted), 비밀·민감 정보는 꼭 필요할 때만
  - "Browser availability can depend on rollout and your workspace settings."
- Chrome 웹스토어 공식 등록 페이지(제공: OpenAI): https://chromewebstore.google.com/detail/chatgpt/hehggadaopoacecdllhhajmbjkdcmajg
  - 사용자 7,000,000 users (2026-10-16 확인), 버전 1.26.1005.11759, Updated October 16, 2026 (검색 스니펫상 10/15)
  - 기능: 로그인된 사이트 리서치, 데이터 입력, 파일 일괄 다운로드, 탭 정리, 활성 브라우징을 빼앗지 않고 백그라운드 작업, 기록·업/다운로드 시 항상 허락 요청
- OpenAI Help Center ChatGPT release notes: https://help.openai.com/en/articles/6825453-chatgpt-release-notes
  - 9월: 브라우저 확장 Edge·Brave·Opera·Vivaldi 지원 추가 (Opera는 side chat 없음)

## Uncertainties / careful wording
- 이번 업그레이드의 OpenAI 공식 발표문(블로그·릴리스 노트 항목)은 찾지 못함(X 검색도 0건). 날짜는 슬라이드에 넣지 않고 "업그레이드"로만 표현. 웹스토어 업데이트일(10/16)과 The Verge(10/15 UTC) 기준.
- 플랜별 이용 가능 여부(무료/Go 포함 여부)는 공식 문서에 명시 없음 → "순차 적용·워크스페이스 설정에 따라 다름"으로만 씀.

- "(예시) 거래처 3곳 견적 비교", "(예시) 지시문"은 직접 만든 예시(The Verge가 전한 OpenAI 샘플 질의 '탭의 공급업체를 가격·기능·출처 링크로 비교표에'를 한국식으로 각색).
