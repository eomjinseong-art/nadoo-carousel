GPT-4o·4.1 API 종료, 2027년 1월 14일 전에 바꿀 것

자동화에 옛 모델을 걸어 뒀다면 1월 14일부터 멈출 수 있습니다.

오픈AI가 10월 14일(미국 시간) 개발자들에게 GPT-4o, GPT-4o mini, GPT-4.1, GPT-4.1 mini를 2027년 1월 14일 API에서 없앤다고 알렸습니다. 이 모델들로 미세조정(맞춤 학습)한 모델도 같은 날 함께 종료됩니다. 공식 대체 모델은 네 가지 모두 GPT-6 Luna입니다.

챗GPT 앱만 쓴다면 바뀌는 건 없습니다. 이번 공지는 API, 즉 다른 앱이나 자동화 툴이 오픈AI 모델을 불러 쓰는 통로에 대한 이야기입니다.

요금(100만 토큰당, 오픈AI 공식 단가)
GPT-4o: 입력 2.5달러, 출력 10달러
GPT-4.1: 입력 2달러, 출력 8달러
GPT-4o mini: 입력 0.15달러, 출력 0.6달러
GPT-6 Luna: 입력 0.1달러, 출력 0.5달러

주의할 점
Luna는 생각 단계(추론)가 기본으로 켜져 있어서 답변 속도와 실제 사용량은 직접 돌려 보고 확인해야 합니다.
Luna는 미세조정을 지원하지 않습니다. 맞춤 학습 모델을 쓰고 있다면 대체 방법을 미리 정해 두세요.
마이크로소프트 애저(Azure OpenAI)로 쓰는 경우 같은 모델의 종료일은 2027년 4월 14일입니다(마이크로소프트 문서 기준, 바뀔 수 있음).
개발자라면: Chat Completions에서 함수 호출은 reasoning_effort를 none으로 둘 때만 지원되고, Assistants API는 Luna를 지원하지 않습니다.

확인 체크리스트
① 자동화·챗봇 설정의 모델 칸에서 gpt-4o, gpt-4o-mini, gpt-4.1, gpt-4.1-mini 찾기
② 같은 입력으로 바꾼 뒤 답변 품질·속도 비교
③ 한 달 요금 다시 계산하기
12월 안에 테스트를 끝내 두면 여유가 있습니다(제안).

공식 안내: https://developers.openai.com/api/docs/deprecations
