# 출처 — Claude Sheets·Claude Whiteboards·Claude Data + 인터랙티브 커넥터 (앤트로픽)

- 공식 발표 (2026-11-10, claude.com Product updates 목록 날짜 확인): https://claude.com/resources/articles/sheets-whiteboards-data
  - Claude Whiteboards·Claude Sheets 베타 출시, Claude Dashboards → Claude Data로 이름 바꿔 정식(GA). 모든 유료 플랜(all paid plans)
  - Sheets: 프롬프트 한 번으로 탭·수식·서식·드롭다운 스프레드시트 생성(예: campaign tracker, hiring budget), 셀 편집 시 변경 표시, 팀 공유. 현재 단순 기능 → 엑셀 전체 기능은 .xlsx/CSV 내보내기 또는 Claude for Excel
  - Whiteboards: 말로 푼 계획 → 담당자·날짜 있는 타임라인 보드, 회고 메모 주제별 묶기·사람별 액션 아이템 초안, 문서·덱으로 변환, Lucid·Miro·Vani by Zoho 내보내기
  - Claude Data: Dashboards는 10월 베타 출시. certified queries·live sharing은 베타. 추적 변경·롤백, 캐싱, 디자인 시스템. 데이터 커넥터(웨어하우스·CRM) 필요
  - 웹·데스크톱·모바일 지원
  - 관리자: Team 플랜은 세 기능 기본 켜짐. Enterprise는 Whiteboards·Sheets 기본 꺼짐, Claude Data는 2026-11-19부터 기본 켜짐
- 인터랙티브 커넥터 (2026-11-10): https://claude.com/resources/articles/interactive-connectors-full-tool
  - 지원 커넥터는 대화 옆/전체 화면으로 열림, 열린 페이지·행·파일을 Claude가 수정하고 사용자가 커넥터 액션과 같은 방식으로 승인
  - 웹·Claude 데스크톱 앱, 모든 요금제(all plans)에 순차 적용(새 Claude 경험 적용 시)
  - 예시 도구: Atlassian(Confluence), Notion, Adobe, Box, HubSpot / 시작 도구 Asana, Canva, Carta, Dropbox, monday.com, Smartsheet, Vercel, Webflow (Figma 언급은 금지 규칙에 따라 제외)
- 날짜 목록: https://claude.com/resources/product-updates (Nov 10, 2026 표기)
