배경 지우기 끝, 투명 PNG로 바로 — 바이트댄스 시드림 5.5

배경 지우기 없이 투명 배경 소재를 바로 뽑는 이미지 AI가 나왔습니다.

바이트댄스 시드(Seed) 팀이 2026년 11월 9일 새 이미지 생성 모델 시드림 5.5(Seedream 5.5)를 공개했습니다. 핵심은 세 가지입니다. 첫째, 여러 번 고쳐도 안정적인 편집입니다. 고치지 않은 부분은 픽셀 단위로 그대로 두고 색 틀어짐을 없애, 같은 이미지를 100번 연속 수정하는 시연을 보여 줬습니다. 둘째, 투명 배경(RGBA) 이미지를 처음부터 바로 만듭니다. 완전·반투명 배경을 모두 지원해 따로 배경을 지우거나 테두리를 다듬지 않아도 됩니다. 셋째, 사진에 더 가까운 질감과 더 또렷한 글씨입니다. 빽빽한 작은 글씨도 더 정확하게 그립니다.

바이트댄스 자체 평가 기준으로 중국어·영어 글자 깨짐은 심한 경우 0.4%, 가벼운 경우 1.7%까지 줄었고, 영화·방송과 사무 용도에서는 쓸 만한 결과 비율이 이전 버전(Seedream 5.0 Pro)의 2배를 넘었습니다.

주의: 성능 수치는 모두 바이트댄스 자체 평가입니다. 공식 페이지의 체험 버튼은 드리미나(Dreamina)로 연결되고, API 안내는 아직 없습니다. 상위 Pro 버전은 추후 공개 예정입니다. 상업 이용 조건과 요금은 쓰는 서비스에서 직접 확인하세요.
